# Avatar

A person's photo or initials, at 32, 44 or 64px.

- Use the brand ring (`pd-avatar--brand`) for people recommended or Klicked in this product, and neutral for everyone else.
- Initials are the first letters of the first and last name.
- A hidden or unavailable profile shows the privacy lock, never a guessed photo. Klick never creates shadow profiles.
- With a photo, put an `<img>` inside with `alt` set to the person's name.
