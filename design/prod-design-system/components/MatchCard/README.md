# MatchCard

A recommended person for an event, with the human reason behind the suggestion.

- **Always show why.** The why panel (`brand-soft`) names the shared event, goals or experience in a sentence. Never show a score.
- Show only fields the person allows before a Klick: name, photo, role and company by default.
- **Actions:** Request a Klick (brand), Save for event (secondary icon), Dismiss (ghost icon). Report sits in an overflow menu.
- Consumer provides: person, reason sentence, topic chips, participation state.

**Responsive.** Cards are fluid. Lay lists of them out with `pd-cards`: one column on phones, two from `bp-md`, three from `bp-xl`. Actions stay in one row; on touch the icon buttons are 44px.
