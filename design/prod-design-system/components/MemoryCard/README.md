# MemoryCard

One memory about a person: the note, where it came from, who can see it, and any follow-up.

- **Privacy badge** top right, always. Memories are "Only you" by default.
- **Provenance pills** (dashed, muted) show the event and date, whether the member confirmed it or it was inferred, and attached media. Dashed means "context", not "action".
- **Follow-up intent** is a checkable row with its due state; overdue uses `warning` with the clock icon.
- Consumer provides: note text, privacy level, provenance items, optional follow-up.
