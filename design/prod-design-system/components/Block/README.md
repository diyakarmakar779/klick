# Block

The product brick: Prod :D's identity unit, in the product's colour with 1, 4, 6 or 8 studs.

Each product owns one colour and one stud count. Which product gets which is still open; Klick previews in every colour through the themes.

- Use the block for identity moments: the app mark, the Klick success moment, empty states, the AI's private-assistant mark. Never as decoration in lists or cards.
- The one-stud block has the same 2×2 body as the four-stud block, with one centred stud.
- A brand panel with text (`pd-brand-panel`) uses `brand-fill` and `brand-foreground`, so its heading and body both pass AA. Text set straight on the bright block colour, such as a marketing headline, uses `brand-on-large`: near-black in every product.
- Fill is `brand`, the edge and stud shadow are `brand-edge`. Set `--u` for size (one stud pitch).
- This flat block is the UI stand-in. The smooth-plastic 3D renders in the brand folder are the reference for marketing and the eventual logo.
