# Alert

An inline banner for source state, privacy explanations and recoverable errors.

- **Tones:** info (neutral, because blue is a product colour), privacy, warning, destructive, success. Each pairs a `*-soft` surface with its solid colour on the icon only; text stays `foreground` and `muted-foreground`.
- **Title** says what happened in plain words. **Body** says what to do next. Errors never apologise and are never vague.
- One action at most, as an outline small button on the right: Reconnect, Retry.
- Privacy alerts explain defaults where people make sharing choices (capture, share fields, AI). Don't repeat them on every screen.
