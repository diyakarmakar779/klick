# Badge

Short state labels: participation, connection state, status and privacy.

| Tone | Class | Means |
|---|---|---|
| neutral, outline | `pd-badge--neutral`, `--outline` | Plain facts: Invited, Hosting, a topic. |
| brand | `pd-badge--brand` | The member's own relationship to something: Planning to attend. |
| solid, strong | `pd-badge--solid`, `--strong` | Klicked. Reserved for a mutual connection. Strong is the darker fill with white text. |
| success, warning, destructive | `--success`, `--warning`, `--destructive` | Accepted, Overdue, Blocked. Warning always carries an icon. |
| privacy | `pd-badge--privacy` | Who can see something: Only you, Mutual, Event-visible, Revoked. Always with its icon (lock, users, eye). |

Privacy badges are violet in every product so visibility reads the same everywhere. Never use brand colour to signal privacy.
