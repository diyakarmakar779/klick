# Choice

Checkboxes for picking several things, radios for exactly one.

- Checkboxes collect choices that are confirmed together, such as the fields to share before sending a Klick request.
- Radios pick one state, such as participation: Hosting, Invited, Planning to attend. Never offer "Attended" unless a source verifies it.
- Checked fills are `primary`. A second line in `muted-foreground` says what the choice means for visibility.
